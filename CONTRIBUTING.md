# Contributing

Thank you for your interest in Unification Network Intelligence.

This repository currently accepts documentation corrections and well-sourced suggestions. Do not submit live secrets, private operational data or scraped user-specific information.

For proposed changes:

1. Explain the affected metric or module.
2. Include a verifiable source and observation time for factual claims.
3. Distinguish verified measurements from interpretation.
4. Preserve the separate meanings of LIVE, COMPLETE, PARTIAL, STALE and NO DATA.
5. Avoid changes that would expose private collector endpoints or internal data.

Source-code contributions will be considered only after a reviewed source release and a clear license decision.
